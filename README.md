# MAX Launcher для LDPlayer 9

Утилита для автоматизированной настройки, безопасного запуска и контроля среды эмулятора LDPlayer 9 с целью использования мессенджера MAX на ПК.
Позволяет использовать мессенджер MAX в изолированной от личных данных среде.

## Назначение программы

1. **Безопасный запуск:** Обеспечивает изолированный запуск мессенджера MAX на ПК или ноутбуке через эмулятор Android.
2. **Контроль данных:** Предоставляет механизмы управления буфером обмена и файлами в общей папке (Shared Folder) между хост-системой и эмулятором.
3. **Блокировка рекламы:** Автоматически нейтрализует встроенную рекламу и рекомендательные блоки LDPlayer, заменяет стандартный интерфейс на легкий лаунчер **PCL Launcher**.

## Системные требования

- Операционная система: Windows 10 / 11 (x64).
- Установленный эмулятор **LDPlayer 9** (актуальной версии).

## Инструкция по установке и использованию

Для корректной работы выполните следующие шаги в указанном порядке:

1. **Установка эмулятора:** 
   Скачайте и установите [LDPlayer 9](https://www.ldplayer.net/) с официального сайта.

2. **Развертывание утилиты:** 
   Распакуйте содержимое архива `MAX_Launcher.zip` непосредственно в корневую папку установленного эмулятора LDPlayer 9 (по умолчанию: `C:\LDPlayer` или путь, указанный при установке).
   Создайте ярлык `MAX_Launcher.exe` на Рабочем столе для удобства запуска лаунчера.
   
4. **Запуск программы:** 
   Запустите файл `MAX_Launcher.exe`. 
   
5. **Автоматическая настройка:** 
   При первом запуске программа самостоятельно:
   - Подключится к эмулятору через ADB.
   - Установит и активирует PCL Launcher.
   - Отключит стандартный лаунчер LDPlayer и магазин приложений (`com.android.ld.appstore`).

   *Замечание. Чтобы не менять стандартный лаунчер, удалите файл `PCL.apk`*
   
6. **Установка приложения MAX:** 
   Если приложение MAX еще не установлено, перетащите его APK-файл в окно эмулятора или установите его через интерфейс PCL Launcher.
